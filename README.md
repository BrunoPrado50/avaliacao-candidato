Projeto prático desenvolvido no curso de Inteligência Artificial e Desenvolvimento Web no **SENAI**, combinando conceitos fundamentais de lógica de programação em **JavaScript Vanilla** com desenvolvimento assistido por modelos de linguagem (IA Generativa) e controle de versão.

---

## 📌 Sobre o Projeto

O objetivo principal desta aplicação é realizar a **triagem automática de vagas**, validando dados do usuário (nome, idade e altura) com base em regras condicionais predefinidas. Apresenta uma interface moderna em estilo *Glassmorphism* (efeito de vidro) e elementos neon.

Além do desenvolvimento da interface web, o projeto exercitou a transição do papel do desenvolvedor de apenas "escrever código do zero" para o de **arquiteto e auditor de IA**, utilizando prompts estruturados para gerar a base do código e realizando a revisão humana para garantir integridade e correção lógica.

---

## 💡 Conceitos e Aprendizados Abordados

- **Estruturas de Dados em JS Vanilla**: Diferença prática entre **Arrays** (`[]`) e **Objetos** (`{}`).
- **Lógica de Triagem Interativa**: Coleta de entradas do usuário para liberar ou bloquear a candidatura conforme os critérios (`altura >= 1.70` e `idade >= 18`).
- **Arquitetura Modular**: Separação das responsabilidades em arquivos distintos (`index.html`, `style.css` e `script.js`).
- **Engenharia de Prompts de 4 Pilares**: Criação de prompts eficientes no **Google Gemini / AI Studio** configurando Persona, Tarefa, Contexto e Formato.
- **Interface UI/UX**: Implementação de modais (popups) e design responsivo com CSS moderno.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3**: Estrutura semântica e estilização visual da interface.
- **JavaScript Vanilla**: Lógica de decisão, condicionais e manipulação DOM (sem frameworks).
- **Google Gemini / AI Studio**: Ferramenta de IA Generativa para auxílio na codificação.
- **Git & GitHub**: Versionamento local e hospedagem remota.
